# TWWHD Randomizer logic

These files are unmodified copies of the logic data used by version 1.2.0 of
the TWWHD Randomizer app tracker:

- `world.yaml`
- `macros.yaml`
- `location_data.yaml`
- `entrance_shuffle_table.yaml`

Source: https://github.com/SuperDude88/TWWHD-Randomizer/tree/1.2.0/logic/data

They are kept separate from the hint tracker's editable item and location
lists. Update this whole set together when supporting a newer randomizer
version so that room, location, macro, and entrance definitions stay in sync.
